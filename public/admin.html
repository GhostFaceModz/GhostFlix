💾Backup

One click downloads every GhostFlix Supabase table (accounts’ lists, history, profiles, reports, chat, roles…) plus the app store as one JSON file. Keep it somewhere private — it contains user data.

🔔Push notifications

Viewers opt in under Settings → Preferences → Notifications. They get a push when a series in their My List / Continue watching gets a new episode, or a “Remind me” title comes out. iPhone/iPad only works from the installed home-screen app. The sender runs hourly (Supabase cron) and while the server is awake.
